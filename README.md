# 퇴사자 처리 자동화

퇴사자가 발생하면 이름·퇴사일만 입력하고, 여러 사이트를 순서대로 열어
퇴사 처리를 도와주는 로컬 앱이다.

- **브라우저 사이트**(그룹웨어·업무사이트·VPN 등): Playwright 로 사이트를 열고,
  사용자가 직접 로그인한 뒤 자동으로 검색/입력을 진행한다.
  기본값은 **저장/제출 직전에서 멈춰** 사람이 최종 확인하도록 한다.
- **API 사이트**(M365/Entra): 브라우저 없이 Graph API 로 계정 차단·세션 만료·
  라이선스 회수를 처리한다.

진행상태는 `data/progress.json` 에 저장돼, 중간에 끊겨도 이어서 할 수 있다.
동명이인은 없다는 전제로 이름을 대상 키로 사용한다.

## 가장 쉬운 방법 (Windows, 명령어 입력 없이)

1. **`install.bat` 더블클릭** — 최초 1회, 필요한 것 자동 설치
2. **`start_app.bat` 더블클릭** — 앱 실행 + 브라우저 화면 자동으로 열림
3. 앱에서 이름·퇴사일 입력 → **시작** → 사이트별 **[열기]** → (자동으로 열린 창에서
   로그인) → **[자동 처리]**

앱을 끄려면 검은 창에서 `Ctrl+C` 또는 창을 닫으면 된다.

## (수동) 설치·실행

```bash
pip install -r requirements.txt
playwright install chromium
python app.py
# 브라우저에서 http://127.0.0.1:5000 접속
```

## 사용 흐름

1. 이름 + 퇴사일 입력 → **시작**
2. 사이트 목록이 순서대로 표시됨
3. 각 사이트에서
   - 브라우저 사이트: **열기** → (열린 창에서 직접 로그인) → **자동 처리** → 확인 후 **완료**
   - API 사이트: **자동 처리** (로그인 불필요) → **완료**

## 사이트 추가/수정

- 각 사이트 시나리오는 `automation/sites/` 아래 한 파일씩.
  `SiteScenario` 를 상속해 `run(page, employee)`(브라우저) 또는
  `run_api(employee)`(API)를 구현한다.
- 만든 시나리오를 `automation/registry.py` 의 `SCENARIOS` 리스트에
  **처리 순서대로** 등록하면 UI 체크리스트에 자동 반영된다.

### 그룹웨어 시나리오 (작성 중)

`automation/sites/groupware.py` 는 아직 셀렉터가 비어 있는 템플릿이다.
실제 그룹웨어 관리자 화면의 HTML(F12 → Elements)을 확인해
검색창·결과 행·퇴사일 입력칸·상태 선택 셀렉터를 채우면 동작한다.

## M365 연동 (선택)

`.env.example` 을 `.env` 로 복사하고 Entra 앱 등록 정보를 채운다.

```
M365_TENANT_ID=...
M365_CLIENT_ID=...
M365_CLIENT_SECRET=...
```

필요 권한: `User.ReadWrite.All` (관리자 동의).

## 보안 주의

- 로컬(127.0.0.1) 전용 앱이다. 사내망 밖으로 노출하지 말 것.
- `.env`, `data/progress.json`, 브라우저 프로필은 git 에 커밋되지 않는다.
